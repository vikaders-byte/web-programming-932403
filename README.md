Данный проект был создан Таргаевой Викторией Александровной, студенткой 3 курса ТГУ ИПМКН.
Цель: выполнение лабораторной работы по дисциплине "web-программирование"
Задача: создать HTML-сайт по теме "Волонтёр и социальный активист" в красно-белых тонах, используя инструменты HTML5 и CSS3.
Код должен содержать в себе:
 <header> – шапка с именем/фамилией студента и заголовком страницы.
 <main> – основной контент.
 Две секции <section>: «Навыки» (маркированный список) и «Проекты»
(нумерованный список из 3–4 пунктов).
 <aside> – боковая панель с краткой информацией (например, «Любимые
технологии»).
 <footer> – подвал с копирайтом и годом.
 Одно изображение (портрет/аватар) с атрибутами src, alt, width, height.
 Форма обратной связи: поля «Имя» (type="text"), «Email» (type="email"),
«Сообщение» (<textarea>), кнопка отправки. У всех полей – атрибуты name и
placeholder.
