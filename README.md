Данный проект был создан Таргаевой Викторией Александровной, студенткой 3 курса ТГУ ИПМКН.
Цель: выполнение лабораторных работ по дисциплине "web-программирование"
Задача: создать HTML-сайт по теме "Волонтёр и социальный активист" в красно-белых тонах, используя инструменты HTML5 и CSS3.

Код должен содержать в себе:
    <header> – шапка с именем/фамилией студента и заголовком страницы.
    <main> – основной контент.
    Две секции <section>: «Навыки» (маркированный список) и «Проекты» (нумерованный список из 3–4 пунктов).
    <aside> – боковая панель с краткой информацией (например, «Любимые технологии»).
    <footer> – подвал с копирайтом и годом.
    Одно изображение (портрет/аватар) с атрибутами src, alt, width, height.
    Форма обратной связи: поля «Имя» (type="text"), «Email» (type="email"), «Сообщение» (<textarea>), кнопка отправки. У всех полей – атрибуты name и placeholder.

Для второй лабораторной требуется прямое использование инструментов CSS и создание отдельного файла для задания стиля страницы.

Файл CSS должен содержать в себе следующие компоненты:
    CSS переменные в :root для цветов и шрифтов.
    Примеры позиционирования: static, relative, absolute.
    Состояния элементов: :hover, :active, :focus, :visited.
    Контрастность текста не менее 4.5:1.

Для третьей лабораторной требуется освоить инструменты Flexbox и Grid для одномерных и двумерных макетов, а также принципы адаптивной вёрстки.
Файл CSS должен содержать в себе:
    Flexbox: навигационное меню (горизонтальноеБ адаптивное) и карточки (3-4) в ряд
    Grid: галерея/дашборд(2-3 колонки, 2-3 строки).
    Медиа-запросы для планшетов и телефонов; отсутствие горизонтальной прокрутки
    Контрастность текста не менее 4.5:1. Семнтически верные теги для карточек
